I had a surprisingly frustrating 40-minute interview with ChatGPT 

Ask ChatGPT to mock-interview you for a system design/coding questions
  
It'll ask good questions. You'll type good answers. And forty minutes later, you'll realize nothing actually happened — no diagram/coding editor exists anywhere, nothing got verified practically doing something, and it can't come back to something you said ten messages ago and press on it automatically.

That didn’t feel like an interview.
It felt like a chat window 🤔
We spent the last few weeks trying to figure out what's actually missing — and it's not a smarter prompt. It's tools. An LLM that can chat like an interviewer and an LLM that can act like one are two different products.

Give it hands, and here's what changes:

The pen. Draw a system design and it stays on the canvas, not buried in a chat log. It points right back at specific box like Feed cache node in the canvas and asks "does this hold for a user with a million followers posting nonstop?"
  
The flashcard. No hiding in a paragraph. Pick A, B, C, or D — right now.
  
The covered hand. Predict the code's output before you're allowed to run it. Then it checks you against the real result, not your explanation of it.
  
The highlighter. After you write the code, it circles two exact lines and asks why only one runs. Not a generic follow-up — a follow-up on what you actually wrote.

And this is where we’re taking it next at Trainer Twin (Forever Learning):
✅ Resume + JD-based interview questions and more customized experience.
✅ Memory across rounds so round 3 can come back to a trade-off from round 1.
✅ Rubric-based reports sent via whatsapp/email.

And eventually, signals like pace, pauses and filler words.
That’s where we’re at right now.
And the question we keep coming back to:

What’s the one thing can we build to make it more personalised for a mock interview? Comment it! We'll let you know after building it 😃
