What if we change the narrative and start thinking big?

Sometimes we need to step out of our comfort zone and start doing things differently, particularly when we are stuck in the "I'm not good enough" mindset.

Skills can be learned, negative visions can be changed.

We need to find our inner motivation and start doing something good for ourselves.

So, next time you think "everybody is better than me", maybe try to rephrase it as "I haven't learnt that yet, but I'm working on it".
