How does hoisting works in JavaScript if it is interpreted ? Let's learn some sequence of questions around this topic, which is commonly asked in ReactJS/JS interviews.

Question 1:
Is JavaScript an interpreted or compiled language ?

Answer:
Most get confused when I ask this question. Right answer is JavaScript is interpreted.

Question 2:
What is interpretation ?

Answer:
In simple words "Interpretation means line by line execution"

Question 3:
What is hoisting in JS ?

Answer:
Because this question became very common in interviews, many know this answer. Right answer is "The process whereby interpreter appears to move the declaration of functions, variables or classes to the top of the scope, prior to the execution of code"

In simple words "If a function is declared in line number 2, you can invoke it from line number 1 because of hoisting".
