In interview perfection v/s completion always completion matters the most. 

1. Given a problem break it down it is smaller chunks. 

2. Ex : if you're asked to build password strength check on UI,  building Ui is one part of it and functionality is another. 

3. Here, first make sure the functionality of verifying the password is working as expected.

4. In the given time whatever the best Ui and logic that you can build try to do it.

in a pursuit to build a perfect product do not end up not completing the given problem. Like i mentioned above perfection v/s completion always completion has priority.
