If you're giving a frontend developer interview for seniors roles then do not make below mistakes.

1. Don't blabber in the interview. If you aren't sure about the answer, don't guess it. 

2. Don't get blank too often in the interview. One or two times it is fine, but if you get blank and unanswerable too often, then that's not a good sign.

3. For any given scenario, think holistically and answer. Ex: Do not forget to mention how to handle the edge cases, error scenarios etc.

4. Don't make silly mistakes. Ex: When the token expires, how will you get the fresh token ? don't answer it as "I will make an API call by passing user name". 

No one wants to hire a senior and coach them. Companies will look for someone  who can coach the juniors. Try to portray those skills in the interview. Now if you're preparing for the interview, answer the 4th question in the comments section.
