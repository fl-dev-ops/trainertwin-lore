(Day 4 of #10dayChallenge) Frontend developer interviews answers you give v/s answers you should give.
Question 1: Can you write a simple #typescript function to add two numbers and return the result ? 
❌ Answer (Most common wrong answer):
-------------------------------------------------------------------------------
const add = (num1, num2) => {
      return num1+num2;
}
-------------------------------------------------------------------------------

Question 1: Can you optimise this function ? 
❌ Answer: Most try to add console.log inside the function.

✅ Right answer:
In above question,
1. Candidates need to ask the interviewer what is the highest and lowest number that can be passed to the add function ? 
2. How to handle the scenario when any one or both the values are not passed ?
3. After that, as the question is specific to #typescript the answer should contain the type of variable and return types. 

📖 Lesson for today: "Whenever an interviewer asks a simple question it can be for 2 reasons. One interviewer wants to extend that question to ask more completed questions or the question just appears to be simple."
