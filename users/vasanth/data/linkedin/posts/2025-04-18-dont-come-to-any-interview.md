Don't come to any interview, without having a local setup ! 

1. In backend interviews you may need to write a code for an api and run it.

2. In UI rounds you may have to write code and run unit testing.

Though, for simple programs you can easily run online, if it requires some additional library / capability to run unit testing then online editors don't perform well.

You will loose a alot of time in juggling with these online tools, which will take away valuable time from your interview.

So, before going to next interview, make sure you have a solid local setup.
