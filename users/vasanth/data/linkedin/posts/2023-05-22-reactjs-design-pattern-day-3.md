Question 1:
What are prototypes in JavaScript ?

Answer:
Most don't answer this way but the right answer is "Every object in JavaScript has a built-in property, which is called its prototype."

Question 2:
When to use prototype patterns in JavaScript ?

Answer:
Most don't know the exact answer. In simple words "Since all instances of any class have access to the prototype, it's easy to add properties to the prototype even after creating the instances."
Ex: If you want to add custom array to method to Array prototype then you can do it and all future arrays can access that property.
