Few days back in our cohort 2 batch, discord community below problem was discussed. I felt it is interesting and share with you all. 

The output of this block of code is : 2,1,1 

Explanation: 
Javascript treats variable and function declarations differently during hoisting. 

Function declarations are fully hoisted, whereas var only hoists the variable declaration—not its value.

During the creation phase, myfunc initially points to the function declaration (console.log('2')).

After execution reaches the arrow function assignment, myfunc is reassigned to the arrow function (console.log('1')).
