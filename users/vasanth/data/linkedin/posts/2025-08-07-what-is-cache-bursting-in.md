What is cache bursting in web deployment ?

1. You should ensure everytime you create new name for the primary resources. Ex: instead of main.css it should be main123.css

2. Because, for better performance of the application modern browsers cache the resources.

3. So, even after the new deployment, they might still point to old resources. If you name it uniquely then browsers will burst the cache and use the new resource.
