I asked the candidate "What is the difference between Context API and Redux ?" Candidate's answer

"Redux is suitable for larger applications and Context API for smaller apps". I further asked the candidate  "Can you define large and small applications" ? Because it is difficult to quantify what is large and small ? They are perspective driven. 

If you ever get this question in the interview my answer would be "If you have 2 screens which are not directly related to each other and still want to share some state then Redux should be a good choice. Context API is suitable for almost all the other flows. Performance point of view Context API works better compared to Redux".
