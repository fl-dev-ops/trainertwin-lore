When we speak of data being stored as Trees, graphs, list etc on backend, I'm sure most frontend developers do not know, what is the difference between Logical Representation v/s Physical Storage in Databases. Let me explain the difference today;

**** Logical Representation: When we say data is stored in a tree, graph, or any other data structure format, we are referring to how the data is logically organised or structured in memory while processing.

****Physical Storage in Databases: On the physical level, most databases store data in blocks on disk or solid-state storage. The data is often stored in a more compact, linear format, such as rows or columns of tables in relational databases (RDBMS), or as documents or key-value pairs in NoSQL databases.

So data never gets stored in tree/graph format on DB, it is just converted to that format while processing. Any backend developers who is reading this post, can add more context in the comments section.
