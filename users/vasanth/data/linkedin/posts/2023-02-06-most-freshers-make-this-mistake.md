Most #freshers make this mistake while #learning #webdevelopment. They start learning #webdevelopment by learning HTML and CSS. Nothing wrong with that but most forget to learn how the web works.
If you're a fresher and want to learn web development, you can start by learning these concepts first.

1. What is www, http, https and different protocols like TCP, UDP when to use what ?
2. How does DNS work ? why DNS is essential. 
3. When you load a web page how data gets loaded. Which loads first ? (HTML, CSS or JS ?)
4. How JavaScript works on Browser and many more.
