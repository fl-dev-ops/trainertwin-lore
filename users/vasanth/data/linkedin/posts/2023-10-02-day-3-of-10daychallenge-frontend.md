(Day 3 of #10dayChallenge) Frontend developer interviews answers you give v/s answers you should give.

Question 1: What all steps you take while integrating API into your project ?
❌ Answer: (Wrong answer given by most developers) I will check the API response on Postman and integrate it to my project.

Question 2: Because of some reason what if your backend URL and response structure changes ? 
❌ Answer: I will change the base URL and make necessary code changes across all the files. 

✅  Right answer: "Never couple API calling and your UI related code. Follow below 3 step process instead"
1. Make API Call 
2. Transform the response 
3.Bind the transformed response into your project

Tomorrow if your backend response structure changes you don't have to do any code change in the UI just change the transform function and rest is untouched. 

📖  Lesson for today:  "Never jump into quick implementation. Always try to make your application future proof. Tomorrow if you change from #reactjs to #angular large portion of your code must be re-usable".
