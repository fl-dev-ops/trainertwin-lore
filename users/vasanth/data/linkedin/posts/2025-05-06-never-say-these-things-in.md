1. I only know this piece of the project not the other. 
2. I just installed a package and completed the task. 
3. I made API calls and backend took care of the rest. 
4. My manager, never let me to learn this. 
5. No one asked me to write unit testing for the project. 

Along with being honest, you need to be politically correct in the interview. You're honest answers might sound immature or lack of tecnical knowledge. Make sure you don't do it in the interview.
