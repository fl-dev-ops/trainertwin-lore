Most you have heard that your messages are end to end encrypted on messaging apps like WhatsApp Instagram etc. But what is end to end encryption means ? Let's say there are 2 users - user 1 and user 2. 

1. First user 1 will register their public key on WhatsApp server and store private key on device. The same happens for user 2. 

2. Now if user one wants to send message to user 2, then user 1 uses user 2's public key and encrypt the message.

3. Now this message cannot be decrypted on whatsapp servers. Only user 2 with the private key can decrypt it. 

4. In the case of whatsapp business, where more than one user uses the same app, even for the same user there will be multiple public and private keys based on the device.
