I have observed this w.r.t most developers they develop a blind spot about certain things over a period of time. Unless it is questioned they wouldn't know why they are doing it. Here are few examples:

1. Most front-end developers use utility class to make API calls and they maintain const headers. It doesn't matter whether every API requires those headers or not, still they will be passing it.

2. Always trying to follow some linting rules like the maximum number of lines in a function is 30. If it is more than that then dividing it into 2 functions. Except readability this approach will not reduce any code complexity.

3. Always using arrow functions over normal functions. Assuming arrow functions work faster than normal functions in all scenarios.
