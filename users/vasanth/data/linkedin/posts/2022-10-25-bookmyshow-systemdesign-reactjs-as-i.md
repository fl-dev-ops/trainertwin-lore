#bookmyshow #systemdesign #reactjs  As I mentioned in one of my last posts, I'm currently practising for system design of BookMyshow video. One of the interesting problems of BookMyshow is how to show theatre layouts on screen ? This is a tricky problem because:

1. Almost all the local theatres will have different dimensions. 
2. Most theatres will have different levels of seating arrangement. Ex: Royal class, Club class, Normal etc. 
3. In between walking paths, entry to Balcony and main entrance varies for each theatre. 

Solution:
I will discuss the solution in detail in my upcoming video. But to explain in brief this is just a 2D matrix where each seat has a unique number and empty spaces have a unique value. UI can ignore the empty space and show seat layout for non-empty values. 
If you observe in the below diagram in the first row (E) after seat number 11 the value inside the matrix could be XX where UI will ignore it.
