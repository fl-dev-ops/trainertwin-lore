Facebook news feed frontend system design. Things to know about the news feed system.

1. How to handle pagination: Cursor based or offset based approach and in most cases cursor based pagination is a best approach.

2. How to handle resources: Using webp images over .jpg/.png will improve the image loading much quicker.

3. Search functionality: Combination of denouncing and caching result locally will give a better search performance.

4. How to upload video in a post: If the the video is bulky then split the video into few chunks and upload.
