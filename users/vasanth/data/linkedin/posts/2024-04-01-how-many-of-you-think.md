How many of you think React JS is overrated ?? I started my #career with #jquery and later switched to #angular and finally towards ReactJS and NextJS. A lot of people think  React JS is the most efficient library out there for building web applications. 

1. There is no doubt React JS is better compared to its predecessor but using hooks like useRef, useState and updating states across the application is quite 
cumbersome when a project grows bigger.

2.  Although reconciliation is better compared to traditional re-rendering, it is not the most efficient one. Dirty check techniques used by Angular are better in many cases compared to reconciliation/tree shaking. 

3. As it is a library and not a framework, there is no standard folder structure. Because of which every project follows its own structure and this also becomes complicated after the project grows big.

4. Lack of support for built in state management and routing. Considering it as one of the primary requirements from a library, react officially does not recommend any of these libraries. 

Recently I'm exploring Vue.js Developers and I see it is better in many ways compared to #react. What do you think ? Will #vuejs becomes the next #reactjs ??
