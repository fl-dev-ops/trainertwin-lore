How should be an ideal interview in genAI era ? 

1. Any questions which is purely based on memory is not worth asking. Ex: syntax specific. 

2. Most part of DSA also obselete. If genAI can write a solution for the same problem in few seconds, then there is no point judging a human on that. 

3. Ideal interview should be about discussing candidate's experience in depth and asking questions around it, which are relevant for the role.

4. Focus more on system design and scenario driven questions to understand, how does a candidate thinks. 

5. Bring up a bug in the existing code and ask candidate to live debug and fix it. If needed allow candidate to take external help.
