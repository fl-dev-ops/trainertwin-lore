Frontend system design part -6 

Problem: How to improve the performance of the react website?

Answer: As soon as this question is asked do not jump and try to answer everything you know about the efficiency. 
Primarily we can divide efficiency into 4 parts. 

1. Network calls
2. Loading time 
3. Code level 
4. Caching 

Ask interviewer on what optimisation they are really interested in ? answer accordingly. Ex: if they are concerned about loading time, then speak about light house score, how do you check the loading time in performance tab etc. 

if it is caching, how do you optimise the caching process ? mention it in the comments section.
