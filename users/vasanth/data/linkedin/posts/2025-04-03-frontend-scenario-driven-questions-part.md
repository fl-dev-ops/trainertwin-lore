Frontend scenario driven questions part - 2

Question: How does LinkedIn shows a person is active or not ?

Answer: Definitely this as a feature cannot be fully implemented on client. Here client should get this information from the backend. 
But the problem is what should be strategy? because person can come online any time ! so, my suggestion is understand your requirement and how important it is to update online status. 

If it is something that should be updated very real time, then we can use socket connection. Same connection can also be used for other aspects of chatting. 

If it is something that can be updated periodically then use polling.

now if a user goes offline, how does LinkedIn gets to know about it ? mention it on the comments section.
