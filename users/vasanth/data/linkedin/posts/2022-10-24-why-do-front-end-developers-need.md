Why do front-end developers need to know the concept of trees and how to implement it ? On this happy occasion of Deepavali, I wish happy Deepavali to all and let's learn something useful.

I often get this question from junior and fresher frontend developers, "Vasanth, we never use tree and graph data structures, why should we learn it."

Let me explain with an example why it is required. There is a special tree DS called Merkle tree, where each leaf node contains the hash value of something. Let's say you have four words "One", "Two", "Three", "Four" and hashing of it produces 1,2,3,4. Then the leaf nodes of the tree are presented as shown in the image below. Next layer is built by hashing of 1,2 and 3,4 and goes on till the top.  

This tree is generally used in concurrent document editing especially in maintaining the version history. Difference between 2 trees is used to fetch the updated document. To know more about how it works, watch my GoogleDocs system design video. Link to the video is in the comment section.
