#typescript #bestpractices Don't write interfaces in #typescript use this instead.
Defining types for complex API responses is a tedious, time consuming job for most developers and mostly there is no technical learning in this process. I was also using the same manual process defining the type until last one month. Later I discovered there are a lot of free npm packages that can be used to convert JSON into interfaces.
All you need is call the API on #postman copy the response and pass it to CLI command for any of the below packages and you will get the required interface. Hours of work are converted into seconds using this approach.

1. json2ts
2. json2typing
3. json-to-typing

In case if you have not followed me, you can do it here, I will help you to clear your Software developer interview : Vasanth Bhat
