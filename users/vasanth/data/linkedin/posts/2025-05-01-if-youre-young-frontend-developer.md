If you're young frontend developer and working for a fast phased startup, here are things that you should do.

1. Relay on AI for writing unit testing.

2. Use other agentux ai tools like GitHub copilot since the beginning of project, so that you have a highly maintainable product.

3. Use other ai tools for reviewing your code.

4. Have a solid CI/CD pipeline set-up so that one click prod deployment is possible. 

5. All good to have project rules like maximum number of lines, code structure etc. don't have a hard constraint on it.
