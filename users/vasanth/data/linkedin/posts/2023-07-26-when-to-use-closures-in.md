When to use closures in #javascript ? Most people know what closures are in #javascript and they will be able to give an example for it. But when I ask, give a right use case for it from your experience, most will not be able to do that. Let me give a few use cases below.

1. Let's you want to track the number of button clicks for logging purposes on the screen. Instead of maintaining a state variable for that you can use closure.

2. You have the same functionality but with minor changes. Example calculating url for different API calls. You can have one function named "getUrl" inside which you can have different functions like "getLoginUrl", "getHomeUrl" etc. Return all the functions and use them on a page basis.

3. Definitely most common usage is of setTimeout and setInterval.

4. Used in case of throttling and debouncing. Most would know this but don't recall during the interview.
