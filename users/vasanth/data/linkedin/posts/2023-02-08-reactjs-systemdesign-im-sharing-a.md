#reactjs #systemdesign I'm sharing a system design question today that I couldn't find the optimal approach. I'm tagging people from my #network who could possibly answer this. If you're aware of the solution to this problem, please add it in the comment section.

Problem:
"Lot of mobile and web applications will have overlay screens that will be shown only for the first time after user logs in. Ex: If you login to Leetcode for the first time it will show an overlay screen with next and previous buttons that will explain different components of the website, Ex: where to write code, where to read questions etc. "

Common Implementation: 

"Most people maintain a local variable and default its value is true and after the user logs in and sees the overlay screen they will set it as false. Problem with this approach is, for the entire lifetime of the application, the local variable value needs to be always checked and decide whether to show an overlay screens or not. Considering use case is only once, there should be a better approach to solve this problem."

The only other approach that I thought was, maintaining a different navigation. Even that adds a lot of redundant code.
