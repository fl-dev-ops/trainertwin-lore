Mistakes in frontend developer interview - Ep 3 'Don't get biased'

Interviewer : "Can you build a TODO application with add and delete functionality"
Candidate: "Immediately starts building the application as they might have practiced it. Delete is implemented using the Array.filter method and addition is done by pushing values to Array".

Instead below is what you should do:
1. Ask the interviewer what is the priority ? Styling / functionality / both.
2. What is the sample size that we are looking at ? just 5-10 entries or in thousands/lakhs ? 
3. Depending on the interviewer's answer you solution needs to be optimised. 

Always remember "If the question is easy then double check by asking all the relevant questions to the interviewer."

Ex: "Build a stopwatch for one minute that is accurate." What is the tricky part in this question ? answer in the comments section.
