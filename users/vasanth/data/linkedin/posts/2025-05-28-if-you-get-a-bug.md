If you get a bug in production or during QE cycle, first thing not to do is code level debugging. 

1. First understand why the issue might be caused. Was it encountered during development?

2. What are the recent changes which might have caused it ?

3. Is this a data issue in lower environment? 

4. Is this a requirement that QE is unaware of ?

I can surely tell you atleast 20-30% of bugs can be solved without even doing code level debugging. So, develope this character to fix the issues efficiently.
