Common mistake most React js developers do in the DSA interview round. As most know for frontend developer roles relatively easy DSA questions will be asked. 

For Ex purpose let's take an easy problem: "Check whether a string is palindrome or not."

1. When I ask this question for 1-2 year experienced engineers, 99% solve it using string revese function which is built in javascript.

2. First don't use the built in functions of the crux of the problem can be solved by it alone. 

3.  Second, make sure you ask interviewer, am I allowed to use the built function. 

for above problem if you use the built in function, where is your credibility? 

let me know, will you ask interviewer before asking built in function or not ?
