## State and props detailed explanation in React

**Product:** knowledge · **Type:** offering · **Source support:** not_reviewed
**Publication:** 2025-02-20 · **Author:** careerwithvasanth · **Format:** transcript

### Summary

- State is data that lives inside a component and can change over time; it's managed by the component. Props are data passed into a component from its parent, akin to read-only snapshots, and cannot be changed from within the component.
  - “State is data that lives inside a component itself. It can change over time, and it's up to the component to manage those changes. Props, on the other hand, are used to pass data into a component from its parent.” — [lines 233-233](../../../data/youtube/video/2025-02-20-top-free-ai-mock-interview-tools-you-must-try-in-2025-iGGkmKN8ilw.md) (`youtube-video-2025-02-20-top-free-ai-mock-interview-tools-you-must-try-in-2025-iggkmk-61e01dee86:u000050`)

## Comparison between state and props in React

**Product:** knowledge · **Type:** self_report · **Source support:** not_reviewed
**Publication:** 2025-02-20 · **Author:** careerwithvasanth · **Format:** transcript

### Summary

- State is like the memory of a component, live as long as the component is live; props are like arguments passed to a function, serving as properties conveyed to a component.
  - “So state is a state is nothing but a memory of a component whenever as long as the component is live the state will be live. Whereas the prop is something nothing but a property that you pass to a component. So depending on it's more like you passing a argument to a function that has prop state is a memory of a component that's the difference.” — [lines 229-229](../../../data/youtube/video/2025-02-20-top-free-ai-mock-interview-tools-you-must-try-in-2025-iGGkmKN8ilw.md) (`youtube-video-2025-02-20-top-free-ai-mock-interview-tools-you-must-try-in-2025-iggkmk-61e01dee86:u000049`)
