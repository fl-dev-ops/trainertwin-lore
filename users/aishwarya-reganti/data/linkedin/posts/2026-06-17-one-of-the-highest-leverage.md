🤓 One of the highest leverage lines to add to your CLAUDE.md or AGENTS.md file if you're a voice coder like me and use tools like Wispr Flow to code:

“I'm using voice to text for these instructions. If a word or phrase seems wrong, use the surrounding context to infer what I likely meant. Don't blindly follow transcription errors. Only ask for clarification when the ambiguity changes the outcome of the task."


This one line has saved me a ridiculous number of tiny corrections/confusions.
