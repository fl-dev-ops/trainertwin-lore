⛳ Claude Chat vs. Code vs. Cowork, a cheat sheet of the most common features & skills.

Anthropic has been releasing so many scattered features that I had a hard time putting a clear mental model together. So I did some research, asked around, and created this with help of Claude itself.

It gives a simple high level mind map of how the three tools compare, based only on the features and skills currently supported.

Made this for my own learning, but sharing it here in case it's useful to anyone else trying to make sense of the Claude ecosystem. I'm sure this will look very different in a few months, but for now, it helps to know what each surface is actually built for.
