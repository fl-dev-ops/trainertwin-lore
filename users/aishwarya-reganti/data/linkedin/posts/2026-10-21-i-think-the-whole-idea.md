I think the whole idea of personal agents like Muse, Dot, etc., is super fun. I find it extremely convenient to get work done from my phone. But if you're a heavy Claude Code or Codex user, these agents can seem pretty stupid in comparison, possibly because of the models they're using.

If you ask them to fix complicated PRs or do knowledge work like writing proposals, you've already got all the right skills, context, and instructions loaded in. You're so used to what  Codex can do that you naturally expect these agents to perform at the same level.

But then they mess up something incredibly small. They don't read an important file, overlook an instruction, or forget something you told them just a few turns ago.

It's annoying because you've gotten so used to frontier model capabilities that it's super hard to adjust your expectations when working with something less capable.

The workaround I've found is to tell my Dot to ask Codex to do the actual work instead of attempting it itself. Essentially, I use it as an orchestrator rather than the agent doing the work.
I really hope we get the option to use better models with these personal agents.
