🌶️ IMO, the hottest skill to learn in AI over the next few years will have less to do with building agents, and a lot more to do with AI security!


😅 When everyone's busy building and spawning agents who understand what risks they are prone to and what attack surface areas they are opening up 


Over the past few months, we've seen how quickly vulnerabilities, supply chain risks, and tool connected systems can create serious problems for agent-native companies.


This paper by Google DeepMind explains why AI security is going to matter even more as agents become common.

- The paper argues that as AI agents start browsing the web, using tools, reading documents, calling APIs, storing memory, and coordinating with other agents, the web itself becomes an attack surface.

- The authors call these attacks AI Agent Traps. These are adversarial pieces of content placed in digital environments to manipulate agents into wrong beliefs, unsafe actions, data leaks, collusion, or bad decisions.


⛳ The paper categorizes these traps based on which part of the agent they target and builds a really extensive taxonomy:

- Content Injection Traps target what the agent sees. For example, hidden instructions in HTML, CSS, metadata, invisible text, images, Markdown, LaTeX, or dynamically rendered web content.

- Semantic Manipulation Traps target how the agent reasons. These don't always look like attacks. They can bias the agent through framing, sentiment, authority cues, misleading context, or repeated narratives.

- Cognitive State Traps target memory and learning. These can poison RAG corpora, long term memory, examples, feedback, or internal memory stores, so the attack carries forward into future sessions.

- Behavioural Control Traps target what the agent does. These include embedded jailbreaks, data exfiltration, or malicious sub agents being created inside a trusted workflow.

- Systemic Traps target groups of agents. These are attacks where many agents react to the same signal and collectively create failures, such as congestion, cascades, collusion, or manipulated consensus.

- Human in the loop Traps target the human supervising the agent. The agent becomes the delivery mechanism for phishing, approval fatigue, overly technical summaries, or automation bias.

It's a great read to understand just how much damage can be done when AI agents go mainstream and IMO AI security is going to be one of the highest leverage areas to learn and work on.
