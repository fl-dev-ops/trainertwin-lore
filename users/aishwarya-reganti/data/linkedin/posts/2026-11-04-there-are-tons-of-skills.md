There are tons of skills people are publishing and building. But how do you know if they’re worth your time or if they’re actually helping you?

Google published a nice article with five rules for evaluating your skills:

- First, check if the agent is even loading the skill. Similar descriptions can make it pick the wrong one. Scan for security issues too.

- Test in a clean environment. Saved credentials and settings on your laptop can hide failures.

- Run the same tasks with and without the skill, multiple times. A single successful run doesn’t tell you much.

- Score correctness, efficiency and security separately. Google found agents reading answer files to game the eval, so keep grading materials out of reach.

- Look at what you’re putting in the skill. In their tests, habits like checking CLI flags before deployment helped more than dumping API docs into context.
