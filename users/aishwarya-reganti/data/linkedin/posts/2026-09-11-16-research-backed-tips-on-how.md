16 research-backed tips on how you can save up to 50% on token costs and 10x your results with agents like Claude Code and Codex.

The five levels of optimization I cover:

1. Context audit and setup: clean up stale or conflicting information and set up the instructions and tools an agent needs.
2. Prompt optimization: communicate tasks clearly and structure prompts to reduce errors and unnecessary token use.
3. Task isolation: keep tasks in separate conversations so irrelevant context doesn't pile up.
4. Failure recovery: use rewinds, forks and handoffs to recover when a conversation starts going off track.
5. Loop engineering: let agents repeat work and check results, with clear goals, memory and stopping conditions.
