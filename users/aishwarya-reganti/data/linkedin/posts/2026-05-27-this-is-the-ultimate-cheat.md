🤩 This is the ultimate cheat sheet to building a content operating system using a multi-agent setup on Claude Code with all the prompts and the exact procedure!!

If you've been trying to write content with AI but keep getting back slop, the problem might have a lot more to do with your process than the agent itself. 

We recently conducted a Chai and AI community session led by Akshat Kharbanda, where he went over how you can build a multi agent system with subagents to create a content operating system.

The idea is simple: instead of asking one agent to turn a podcast, webinar, or community session into every possible content format, you split the work across a small team of agents.

Highlights (although I highly recommend reading the substack linked below for the exact prompts and process!)

⛳ Why one prompt usually fails for content repurposing: When you ask the same agent to write a blog, thread, and newsletter, the outputs often collapse into the same voice, same structure, and same examples. 

⛳ How to split the work across subagents: The session walked through a setup with separate agents for summarizing, writing different formats, and reviewing the outputs. Each agent has a specific job, its own context, and clearer boundaries.

⛳ Why voice files matter more than people think: A lot of AI content feels generic because the system doesn’t have strong shared voice rules or format specific rules. We discussed how to separate your overall voice from the rules for each format, so a thread, blog, and newsletter don’t all sound like the same piece resized three times.

⛳ Why QA and memory are essential: The system also needs a reviewer that checks for factual drift, repetitive hooks, and cross format repetition. It also needs memory, so it doesn’t keep opening every post the same way over and over again.

This is a very practical walkthrough for anyone trying to move from random prompting to an actual content workflow.
