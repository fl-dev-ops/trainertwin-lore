If you’re constantly hitting your token limits with Claude Code or Codex, these are 5 repos to help bring your token usage down significantly.

1. Headroom: https://lnkd.in/g3XHQFvW
Compresses verbose tool outputs, logs and structured data before they reach the model. Keeps the original content available when the agent needs more detail.

2. RTK: https://lnkd.in/gu_nE2sf
Filters noisy terminal output from commands like git, tests and builds. For example, it can collapse hundreds of passing tests while keeping the failures your agent needs to fix.

3. Context Mode: https://lnkd.in/gPiZEUv3
Processes large outputs in a sandbox and indexes them locally. Your agent can search for the relevant pieces without pulling the whole output into the conversation.

4. Serena: https://lnkd.in/g-BKF9xp
Gives your agent code navigation at the function and symbol level. It can find and edit the relevant code without repeatedly reading entire files.

5. ccusage: https://lnkd.in/gePd4cdB
Reads your local usage logs and breaks down tokens and estimated costs by session, model and day. Useful for figuring out which conversations are burning through your tokens.
