🤓 DeepSeek Harness is probably the most viral thing after OpenClaw right now, and it's actually pretty fun to play with.

DeepSeek released its own open source Harness a few days ago, and it's already crossed 150k GitHub stars.

Some nice things I liked:
- Treats everything as a plug in. The model, tools, memory, skills, subagents, agent loop, pretty much everything can be swapped out. You don't even need to use DeepSeek models. You can run local models, bring your own provider, and even plug in Codex or Claude Code as subagents. It feels much less opinionated than most coding agents.

- The observability is pretty cool. You can inspect the trajectory of a run and see what tools were called, what the subagents did, what got injected into context, and where that context actually came from. Nice when you're trying to figure out why the agent went down a weird path, I've not seen CC/Codex do this well

- It has this fun agent presets thing where you can basically choose the vibe. You can start with coding agent setup, or pick presets for creative tasks etc.

 - It feels pretty composable. Almost like the super app version of a coding harness where you can bring whatever models, tools, agents, and workflows you want and wire them together.
