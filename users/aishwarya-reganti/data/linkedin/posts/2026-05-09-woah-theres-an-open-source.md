🤯 Woah, there’s an open source Claude Design alternative that was released just 10 days ago, already has 34K stars, and can work across different agents. The pace of innovation is just crazy!

Some highlights:
- Runs across 16 coding agent CLIs. It auto detects Claude Code, Codex, Cursor Agent, Gemini CLI, Copilot CLI, OpenCode, Qwen, Hermes, Kimi, DeepSeek TUI, and more. It also falls back to a BYOK proxy for Anthropic, OpenAI compatible, Azure, or Gemini endpoints.

- It comes with 31 composable skills and 72 brand grade design systems. The skills are plain Markdown folders organized by scenario, including design, marketing, ops, engineering, product, and finance. 

- The design systems include Linear, Stripe, Vercel, Airbnb, Tesla, Notion, Apple, Anthropic, Cursor, Supabase, Figma, and more, all structured through a portable 9 section DESIGN.md schema.

- It can generate web, mobile, decks, images, video, and audio, with exports to HTML, PDF, PPTX, MP4, ZIP, and Markdown. 

- One interesting feature is HyperFrames, which renders HTML, CSS, and GSAP compositions deterministically to MP4 through headless Chrome, so motion graphics like product reveals, kinetic typography, and data charts come out of the same pipeline.

- It also has built in anti slop machinery, including a five dimensional self critique gate that scores philosophy, hierarchy, execution, specificity, and restraint before generating the final output. 

- It includes a brand spec extraction protocol, an explicit blacklist of generic AI patterns like purple gradients, generic emoji, and invented metrics, plus an artifact lint API that feeds findings back to the agent for iterative revision.
