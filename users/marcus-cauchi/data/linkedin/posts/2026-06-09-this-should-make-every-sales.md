This should make every sales leader uncomfortable.

For fifteen years, we’ve spent more on sales and got worse at it. More CRM. More enablement. More training. More tools. More dashboards. More methodologies. More content. Now more AI.

And somehow the machine got worse. That should give you pause.

Maybe the problem isn't that these things failed to fix sales performance. Maybe the problem is that, used badly, they helped create the behaviour that dragged performance down in the first place.

CRM is the obvious one.

It gives management the illusion of control. Everything is logged. Everything is staged. Everything has a close date, a next step, a probability, a forecast category, a dashboard. So leadership feels like it can see what is happening.

Visibility is NOT control.

Most of the time it is just a very expensive mirror. And worse, the mirror changes the behaviour. Reps learn what the system rewards. More activity. More updates. More pipeline. More stage movement. More notes. More “next steps.” More stuff that looks good when inspected.

But none of that means the customer is any closer to buying.
That’s the ugly bit.

We trained reps to manage the system, not the sale. We trained managers to inspect fields, not judgement. We trained leaders to confuse dashboard hygiene with execution. Then we acted surprised when forecasts were clean and quarters were still a mess.

This is how false progress gets manufactured.

A deal moves stage, but the customer has not changed. A next step gets logged, but no risk has been removed. A proposal goes out, but no decision process has been understood. Pipeline grows, but quality gets worse. Activity rises, but commercial judgement falls.

And when the numbers don’t improve, what do we do?
We add more.
More CRM rules. More enablement. More training. More tools. More dashboards. More inspection. More AI.

Come on!

At some point, more becomes the problem. A good sales system should make heroics unnecessary. It should help average managers see reality earlier. It should help reps qualify harder, create real buyer movement, and stop wasting time on deals that were never deals. It should make good judgement more common, not make everyone better at feeding the machine.

That’s the missing piece in this fifteen-year failure.

The industry did not build a performance system. It built a reporting system, wrapped it in enablement, fed it with training, and now wants AI to accelerate it.
AI might help. But only if it is plugged into a system that knows the difference between activity and progress.

Plug it into the current mess and it will just make the mess move faster.
The problem was never that sales teams lacked technology.
The problem is we mistook technology for management.

And fifteen years later, the numbers are telling us exactly what that cost.
