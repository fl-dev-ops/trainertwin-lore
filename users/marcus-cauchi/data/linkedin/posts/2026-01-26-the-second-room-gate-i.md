The Second Room Gate

I won’t forecast a capital deal unless it already survives the room I’m not in. If this deal only works while I’m present, it doesn’t work. If approval depends on enthusiasm traveling upward intact, it’s already broken.

The moment feasibility is proven, accountability shifts. Same people sometimes. Different consequences always. That shift is where most deals die.
Not loudly. Not unfairly. Predictably.

So before this advances, pause.

This isn’t about blame. It’s about designing a yes that survives review.

Now answer this without hedging. Someone in this company absorbs the downside if this fails. Name them. If assumptions slip, not collapse, just slip, what happens to them in the next review cycle? When this decision is compressed into one slide by someone protecting themselves, does it still look sane? If it goes wrong, is there a clean exit that looks responsible, or only a long defence? If this is delayed six months, who pays for waiting, and how is that cost explained? If this sets precedent, who else uses it later, and who resents that?

If you can’t answer those, stop calling it timing. It’s exposure without cover. This isn’t about access. I don’t need to be in the second room. I need the deal to be safe when I’m not.

If the downside owner can’t say yes without me present, the process defaults to waiting. Waiting has no name attached. Failure does.

Here’s the refusal that matters. I won’t sell installs as the decision. I won’t sell ROI as protection. I won’t sell confidence as cover. I’ll only sell decisions that are defensible after they’re questioned by people who weren’t in the meetings.

If any one of those answers is missing, the deal is unforecastable by design. If you think this gate breaks under real pressure, I want to know where.
